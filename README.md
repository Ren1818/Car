# Romance PWA

Este repositorio contiene una página web interactiva romántica (PWA) diseñada para mostrar una carta escondida dentro de un sobre, un reproductor de música de fondo con carga de archivo por el usuario, letra descargable, y un contador que calcula el tiempo que llevan juntos desde el 15 de julio de 2026.

La implementación completa del PWA (HTML, CSS, JavaScript, manifest y service worker) se encuentra en la rama `romance-pwa`.

Archivos principales que se crearán en la rama `romance-pwa`:

- index.html
- css/styles.css
- js/app.js
- manifest.json
- service-worker.js
- icons/icon-192.svg
- icons/icon-512.svg

Commit inicial creado para permitir la creación de la rama y posterior generación del PWA.
